# Отчет по созданию статического сайта для проекта «Учёт персонала»

**Версия:** 1.0  
**Авторы:** Мочалин В.Р., Егорова Ю.С., Егорова И.С.  
**Дата:** 07.06.2026  

Данный отчет описывает процесс разработки статического веб-сайта, выполненного в рамках проектной (учебной) практики. Сайт создан на чистом HTML и CSS, без использования фреймворков, и предназначен для презентации информационной системы «Учёт персонала».

## Цель создания сайта

- Представить аннотацию, цели и задачи проекта.
- Показать команду разработчиков и их вклад.
- Вести журнал прогресса работы.
- Собрать полезные ресурсы по теме.

## Требования к сайту (из задания)

1. Домашняя страница с аннотацией.
2. Страница «О проекте» с подробным описанием.
3. Страница «Участники» с указанием личного вклада каждого.
4. Страница «Журнал» с минимум тремя постами о прогрессе.
5. Страница «Ресурсы» со ссылками и медиа.
6. Уникальность дизайна и контента.
7. Наличие графических материалов и видео.

## Выбранный стек

- **HTML5** – структура страниц.
- **CSS3** – стилизация, адаптив, анимации.
- **GitHub** – контроль версий.

## Как был создан сайт

### Шаг 1. Создание HTML-страниц


Каждый HTML-файл имеет одинаковую структуру:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Учёт персонала</title>
    <link rel="stylesheet" href="css/style.css">
</head>
<body>
    <header>...</header>
    <div class="container">...</div>
    <footer>...</footer>
</body>
</html>
```
Важные элементы:

Шапка (<header>) с логотипом и навигацией.

Основной контент (<div class="container">).

Подвал (<footer>) с информацией о команде и годе.

### Шаг 2. Разработка CSS-стилей


Файл style.css содержит:

Сброс отступов (* { margin:0; padding:0; box-sizing: border-box; }).

Основные стили для body, шрифтов, цветов ```css(основной фон #f4f4f4, текст #333)```.

Шапка – ```cssтёмный фон #2c3e50, акцентный цвет #e74c3c.```

Сетка контента – класс .container с максимальной шириной 1200px.

Адаптив – медиа-запросы для мобильных устройств (ширина < 768px).

Стили для карточек, постов журнала, профилей участников.

Прижатый футер – использование flex на body.

Пример прижатого футера:

css
body {
    display: flex;
    flex-direction: column;
    min-height: 100vh;
}
.main-content {
    flex: 1;
}
footer {
    margin-top: auto;
}

### Шаг 3. Наполнение контентом


Главная – краткая аннотация, три карточки (проблема, цель, экономия), кнопка «Подробнее».

О проекте – развёрнутое описание: проблематика, актуальность, целевая аудитория, цель, задачи, риски, экономический эффект, скриншоты интерфейса.

Участники – фотографии, роли, список выполненных задач.

Журнал – минимум три поста с датами и краткими отчётами о проделанной работе.

Ресурсы – ссылки на документацию, встроенное видео с YouTube.

### Шаг 4. Добавление графики и медиа


Изображения – реальные скриншоты интерфейса системы «Учёт персонала» (личная карточка, добавление льгот). Хранятся в папке images.

Фото команды – реальные фото участников.

Видео – вставка через <iframe> с VK видео (о внедрении автоматизированных решений с позиции собственника бизнеса).

### Шаг 5. Адаптивная вёрстка


Медиа-запросы обеспечивают корректное отображение на экранах меньше 768px:

Шапка и навигация становятся вертикальными.

Размер шрифта заголовков уменьшается.

Карточки и профили участников выстраиваются в колонку.

### Шаг 6. Проверка и отладка


Использованы инструменты разработчика в браузере (F12) для проверки сетки, отступов, адаптивности.

Проверена работа всех внутренних ссылок.

Убедились, что футер прижат к низу даже при коротком содержании страницы.

Пример ключевого CSS-кода
css
/* Глобальные стили */
body {
    font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif;
    background: #f4f4f4;
    color: #333;
    display: flex;
    flex-direction: column;
    min-height: 100vh;
}

.container {
    width: 90%;
    max-width: 1200px;
    margin: auto;
    padding: 0 20px;
}

/* Шапка */
header {
    background: #2c3e50;
    color: #fff;
    border-bottom: 3px solid #e74c3c;
}

/* Адаптив */
@media (max-width: 768px) {
    header nav ul li {
        display: block;
        text-align: center;
    }
}
