# Описание проекта «Учёт персонала»

**Руководитель:** Суровец В.А.  
**Команда:** Мочалин В., Егорова Ю., Егорова И.

## Проблематика
Во многих компаниях кадровый учёт ведётся в Excel/разрозненных файлах → ошибки, потеря документов, долгий поиск, риск штрафов.

## Цель MVP
Снизить время на рутинные операции кадровика на 30% за 1 месяц пилота. Обеспечить единое хранилище карточек, документов и истории действий с ролевым доступом.

## Задачи
- Спроектировать БД.
- Реализовать авторизацию и роли.
- Создать интерфейс кадровика (личная карточка, льготы, поиск).
- Внедрить на тестовых данных.
- Подготовить документацию.

## Экономический эффект
Экономия ~12 000 руб./мес на одном кадровике. Окупаемость ~9 месяцев.
